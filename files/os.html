OS NOTES

Operating System (OS) - VTU Notes 1. Introduction to Operating System An Operating System (OS) is system software that manages computer hardware, software resources, and provides common services for computer programs. It acts as an intermediary between users and the computer hardware. Functions of OS: Process Management: Manages processes in the system.
Memory Management: Allocates and deallocates memory.
File System Management: Organizes and stores files.
Device Management: Controls input and output devices.
Security and Access Control: Provides user authentication and file access control.
User Interface: Provides interface for users (CLI or GUI).
2. Types of Operating Systems
Batch OS: Jobs are grouped together and processed without user interaction.
Time-Sharing OS: Allows multiple users to use the system concurrently (e.g., UNIX).
Real-Time OS: Provides immediate processing for critical applications (e.g., embedded systems).
Multiprocessing OS: Uses multiple processors to execute multiple tasks simultaneously. Distributed OS: Manages a group of independent computers to appear as a single system to the user. 3. Process Management A process is a program in execution. It is the basic unit of execution in an operating system. Process States: New: Process is being created. Ready: Process is waiting to be assigned to a processor. Running: Process is currently being executed. Waiting: Process is waiting for an event (e.g., I/O operation). Terminated: Process has finished execution. Process Control Block (PCB): A data structure that stores information about a process, such as process state, program counter, CPU registers, etc. Process Scheduling: The OS selects which process gets to use the CPU using scheduling algorithms like: FCFS (First Come, First Served) SJF (Shortest Job First) Round Robin Priority Scheduling 4. Memory Management Memory management ensures that each process has sufficient memory to execute and that memory is used efficiently.

Memory Allocation: Assigning memory blocks to processes.

Contiguous Allocation: Each process is assigned a single contiguous block of memory.

Paged Memory Allocation: Memory is divided into fixed-size blocks called pages.

Segmented Memory Allocation: Memory is divided into variable-sized segments.

Virtual Memory: Allows the execution of processes that may not be completely in memory by using disk space as an extension of RAM (e.g., paging and segmentation).

Page Replacement Algorithms:

FIFO (First In, First Out)

LRU (Least Recently Used)

Optimal Page Replacement

5. File System Management

The file system manages files and directories in the system. It provides a way to store, retrieve, and organize files.

File Attributes: Name, size, type, location, access control information.

File Operations: Create, Delete, Open, Close

Read, Write, Append

Directory Structure: Organizes files into directories.

Single-Level Directory: All files in one directory.

Two-Level Directory: Separate directories for each user.

Tree-Structured Directory: Hierarchical directory structure.

Access Control: Ensures that only authorized users can access files.



6. I/O Management

I/O Management controls communication between the system and external devices (e.g., keyboard, monitor

, printers).

I/O Devices: May be character-oriented or block-oriented.

Device Drivers: Software that allows the OS to communicate with hardware devices.

Buffering: Used to store data temporarily while being transferred between devices and memory.

7. Deadlock

A deadlock occurs when two or more processes are blocked forever, waiting for each other to release resources.

Conditions for Deadlock:

Mutual Exclusion: At least one resource is held in a non-shareable mode.

Hold and Wait: A process holds one resource and waits for others.

No Preemption: Resources cannot be forcibly taken from a process.

Circular Wait: A set of processes are waiting for each other in a circular chain.

Deadlock Prevention: Ensures that at least one of the deadlock conditions is eliminated.

Deadlock Avoidance: The system uses resource allocation strategies to avoid deadlocks.

Deadlock Detection and Recovery: Detects deadlock and takes corrective action (e.g., process termination).

8. Multithreading

Multithreading allows multiple threads (smaller units of a process) to execute concurrently within a single process. Thread: A lightweight process that shares the same address space.

Benefits:

Improved CPU utilization.

Responsiveness in interactive applications.

Types of Threads: User Threads: Managed by the application. Kernel Threads: Managed by the OS.

9. Synchronization Synchronization ensures that multiple processes or threads can execute concurrently without conflicting over shared resources. Critical Section Problem: The problem of ensuring that only one process/thread is executing in its critical section at a time. Semaphores: A synchronization primitive used to control access to shared resources.

Binary Semaphore: Takes values 0 or 1.

Counting Semaphore: Can take any non-negative integer value.

Mutex: A type of binary semaphore used for mutual exclusion.
